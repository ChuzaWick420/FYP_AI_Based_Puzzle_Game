# Indices
Index must start from `0` instead of any other number (e.g. `1`).

# Direction of cartesian coordinate axes
The $x$ axis is directed from _left to right_ and $y$ axis is directed from _top to bottom_.

# Formulas used
- Graph's Size = $(\text{level number} \times 3) ^ 2$
- Amount of blinders = $\text{level number} \times 2$
- size of blinders = $\sqrt{\text{Maze's width}}$
- Amount of powerups = $\text{level number}$
